# Getting Started With Network Security

On this page, you'll learn about some very important networking protocols, why they should matter to you as a cybersecurity student, and some common network attacks that abuse these protocols

HTTPS

Hypertext Transfer Protocol (HTTP) is the primary way that webpages are sent over a network. It is classified as a request-response protocol that follows the client-server model.

DNS

Domain Name System (DNS) provides a hierarchical and distributed name system for machines and services that exist on the Internet. DNS is the reason you can type google.com in your browser instead of memorizing the IP address of Google's server. Essentially, there are certain servers that exist on the Internet with the sole responsibility of givng IP addresses readable names. These servers put nametags on IP addresses and store them as records. When you type in a website name, part of the loading process is asking a DNS server what IP address owns that nametag.
