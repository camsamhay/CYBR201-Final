# Cyber Camp
An interactive educational website aimed at beginner cybersecurity students. Split into one page per topic, it will teach them network security basics, how to spot and avoid the most common forms of phishing, and provide them with secure web development tips. The phishing page will present a series of real emails and text messages and the user will have to decide whether each one is safe or a phishing attempt.  The network security page will be a mostly descriptive one. It will cover protocols such as DNS, HTTPS, SSL, and TLS. It will also cover common network attacks like DDoS, Man-In-The-Middle, and DNS hijacking, and will show examples with images, videos, captions, and brief write-ups. Finally, the secure web development page will provide tips on the do’s and don’ts of web development and why security should always be a concern. The idea is to give people the practical skills they need to protect themselves in real life and to give them the confidence to go out and use the internet safely. It's an interactive way of bridging the gap between theory and practice.
